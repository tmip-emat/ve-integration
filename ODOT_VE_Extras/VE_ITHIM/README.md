This respository contains the master VE-ITHIM build for RSG, and includes model documentation.

To use ITHIM, clone this repository in the "models" folder of a built VisionEval runtime environment, and adjust the model names in "inst/extdata/config.csv" to the appropriate model names. 

Note that using ITHIM requires: 
1) A fully run VisionEval model.
2) CSV results extracted from the model using the "export()" function present in VisionEval.
